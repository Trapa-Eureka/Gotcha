## 7. 모델 드리프트 대응

교란 효과는 특정 시점의 특정 모델을 상대로 잰 실험 결과다. 유효기간이 있다.

- AI 회사는 몇 달마다 새 모델을 내고, 같은 이름의 모델도 예고 없이 갱신한다.
- 부정행위자는 늘 최신 모델을 쓴다.
- 로컬 모델에서 막힌다고 클라우드 모델에서 막히는 것은 아니다.

운영 규칙:

1. `verify`는 회귀 테스트다. 문항 세트를 고정하고 버전을 매긴다.
2. 재실행 시점: 새 모델 출시, 시험 직전, 도구 버전 변경.
3. 프로파일마다 최신 검증 결과를 저장소에 기록한다. 기준 미달 프로파일은 `deprecated`로 표시하고 `protect` 실행 시 경고한다.
4. 리포트가 일정 기간(예: 30일)보다 오래됐으면 `protect`가 경고한다.
