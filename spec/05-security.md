## 5. 보안 요구사항

| 번호 | 요구사항                                                                                         |
| ---- | ------------------------------------------------------------------------------------------------ |
| S1   | `protect`, `check`는 네트워크 호출 0건. 텔레메트리, 업데이트 확인, 원격 폰트 로딩 없음           |
| S2   | 원본은 읽기 전용으로 연다. 결과는 항상 별도 폴더에 쓴다                                          |
| S3   | 임시 파일은 작업 폴더 안에만 만들고 종료 시 지운다                                               |
| S4   | 로그에는 파일 해시, 프로파일 이름, 시각만 남긴다. 문제 텍스트는 남기지 않는다                    |
| S5   | 워터마크 시드와 수험번호 매핑표는 별도 파일로 분리한다. 기관이 직접 보관한다                     |
| S6   | `--offline` 설정이 켜져 있으면 API 키가 있어도 모든 네트워크 호출을 거부한다                     |
| S7   | 클라우드 검증은 내장된 공개 문항 세트에만 동작한다. 임의 파일은 `--allow-custom`을 명시해야 한다 |
| S8   | 폐쇄망 설치를 위해 의존성을 모두 묶은 단일 실행 파일로 배포한다                                  |

S1은 테스트로 강제한다. 테스트 중 소켓 생성을 막고 `protect`, `check`가 통과하는지 본다.
