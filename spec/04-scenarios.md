## 4. 사용 시나리오 두 가지

대응 기법이 다르므로 프로파일을 나눈다.

| 시나리오                                           | 공격 경로                            | 통하는 기법                                            |
| -------------------------------------------------- | ------------------------------------ | ------------------------------------------------------ |
| A. 디지털 배포 (온라인 시험, 과제, 문제 파일 유출) | 파일을 AI에 직접 업로드, 텍스트 복사 | 텍스트 레이어 교란, 글리프 매핑 변조, 숨은 미끼 텍스트 |
| B. 인쇄 시험 (수능, 자격증)                        | 종이를 카메라로 촬영                 | 인쇄 후에도 남는 시각 패턴, 문항별 미끼, 추적 워터마크 |

A가 구현과 검증이 쉽다. B가 사회적 수요가 크지만 효과가 불확실하다. A부터 만든다.
