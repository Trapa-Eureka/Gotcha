## 11. 단계별 계획

| 단계 | 내용                                                                       | 완료 기준                             |
| ---- | -------------------------------------------------------------------------- | ------------------------------------- |
| 0    | 타당성 실험. 수작업으로 기법 3~4개를 적용해 로컬·클라우드 모델에 넣어 본다 | 살아남는 기법이 하나라도 있는지 판단  |
| 1    | `verify` 먼저 구현. 문항 세트, 촬영 시뮬레이션, 로컬 모델, 리포트          | 변환 없는 대조군 점수가 나온다        |
| 2    | `protect` + `check`, 시나리오 A 프로파일                                   | 결정적 출력, 네트워크 0건 테스트 통과 |
| 3    | `auth`, 클라우드 모델 검증                                                 | 더미 문서로 3개사 모델 리포트         |
| 4    | 추적 워터마크, `--copies`                                                  | 촬영 이미지에서 수험번호 복원         |
| 5    | 시나리오 B 프로파일, 실제 인쇄·촬영 실험                                   | 시뮬레이션과 실촬영 결과 비교         |
| 6    | 단일 실행 파일 배포, 문서                                                  | 폐쇄망 PC에서 설치·실행               |

0단계 결과가 나쁘면 제품 방향을 "차단"에서 "미끼 + 추적"으로 좁힌다. 측정 도구(`verify`)를 먼저 만드는 이유다.
