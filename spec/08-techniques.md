## 8. 교란 기법 목록 (실험 대상)

효과는 전부 가설이다. `verify`로 측정해 살아남은 것만 프로파일에 넣는다.

| 기법                                            | 시나리오 | 예상 효과                          | 비고                                |
| ----------------------------------------------- | -------- | ---------------------------------- | ----------------------------------- |
| 텍스트 레이어 제거(이미지화)                    | A        | 복사·추출 차단. 비전 모델에는 무력 | 접근성 저하                         |
| 글리프 매핑 변조(ToUnicode 교란)                | A        | 텍스트 추출 시 엉뚱한 글자         | 화면 표시는 동일                    |
| 숨은 미끼 텍스트(보이지 않는 지시문, 가짜 조건) | A        | 파일 업로드 시 오답 유도           | DoPE 방식                           |
| 문항별 의미 미끼                                | A, B     | 오답 유도 + 사후 탐지              | 문항마다 설계 필요. 자동화가 어렵다 |
| 미세 도트, 디더링 패턴                          | B        | 불확실. 최신 모델엔 약할 가능성    | 인쇄 품질 의존                      |
| 수험번호별 추적 워터마크                        | A, B     | 차단 아님. 유출 경로 추적          | 촬영 후에도 복원돼야 함             |

제약: 사람 가독성을 해치면 안 된다. 저시력 수험생과 "노이즈가 시험을 방해했다"는 이의제기를 고려해, 각 프로파일에 가독성 수치(대비, 패턴 밀도) 상한을 둔다.
