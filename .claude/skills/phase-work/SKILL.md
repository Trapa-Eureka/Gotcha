# Phase 하나를 진행하는 절차

1. `README.md`의 로드맵에서 해당 Phase의 내용과 완료 기준을 확인한다. 관련 명세는 `spec/`에서 필요한 절만 읽는다.
2. 유료(계획중) 범위에 속하는 일은 하지 않는다. 경계가 애매하면 시작 전에 묻는다.
3. 일을 작은 단위로 나누고, 단위마다 테스트를 먼저 또는 함께 쓴다. 외부 서비스(AI 모델, 키체인)는 로컬에서 결정적으로 도는 대역으로 테스트한다.
4. 지켜야 하는 규칙은 문서가 아니라 테스트나 린트로 강제한다. 예: `protect`, `check`의 네트워크 0건.
5. 끝나면 실제로 실행해서 확인한다. `uv run pytest`, `uv run ruff check .`, `uv run mypy`, 그리고 만든 명령을 직접 실행한 출력.
6. 보고에 넣을 것: 완료 기준별 충족 여부, 실행한 명령과 결과, 검증하지 못한 것과 그 이유, 명세와 다르게 한 것.
7. `README.md`의 기능 표와 로드맵을 실제 상태에 맞게 고친다.
8. 멈추고 다음 Phase 승인을 기다린다. 커밋과 푸시는 요청받았을 때만 한다.
